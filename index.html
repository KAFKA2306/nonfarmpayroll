  • 雇用者数の水準系列は利用できます。現在の公開snapshotは2021-07〜2026-07です。

検証済みrelease vintage

BLS Employment Situationの公表資料に紐づくrelease vintageを部分収録しています。現在の件数・観測期間・公表段階別件数はrelease vintage manifestを正とします。長期revision分布を表すものではありません。

  • release vintage manifest
  • release vintages JSON
  • verified revisions JSON
  • verified revisions CSV

重要な制約

  • coverage不足を推測値で補完しません。
  • level snapshotからrelease-vintage history、改定幅、不確実性を生成しません。
  • 十分な一次公表履歴が揃うまで、長期の改定統計はfail closedのままです。
